# 用户注册页面实验
## 作业内容
做一个用户注册网页，把表格、列表、表单这些知识点一起用上。

## 使用到的标签
header、main、footer语义标签，h1大标题；table、thead、tbody表格；ul、ol、dl三种列表；form表单，还有input、select、textarea、button；JavaScript；外部CSS样式文件。

## 遇到的困难
1. 表格里面colspan合并单元格，一开始不太会写
2. 单选框要求两种label写法，折腾了好久才做对
3. 手机号pattern正则校验，调试了好几次
4. 写JS拿到表单数据，并且打印在控制台
5. 把CSS单独抽出来放到外部文件，保证网页和样式分开

## 解决方法
翻教材例子，打开F12开发者工具查看页面结构，一点点调试表单和JS代码，最后把样式单独分离到style.css。
